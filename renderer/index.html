How to use this search

Type in plain words. The search looks at the customer, company, item description and order number all at once, and every word you type must be found on the same line.

  • Customer or school: hinshaw, st bernard, peru
  • Item: name tags, 29m, senior medals, trophy
  • Dates: 2025, last year, this year, oct 2025, since 2024, 2023 to 2025
  • Order number: 11842
  • Exact phrase: put it in quotes, e.g. "grand champion"
  • Abbreviations are understood (see list below). Small spelling mistakes are corrected when nothing is found.

Using the results

  • Click a column heading to sort. Tick the boxes to pick specific lines.
  • Copy as text copies the ticked lines (or the first 10 shown) in a short format that is easy to paste into a text message or email.
  • Print prints the ticked lines, or all results (up to 500) if none are ticked.
  • Save as spreadsheet downloads every matching line as a CSV file that opens in Excel.

Good to know

  • Prices are the unit price written on each old-store order line. When the old owners combined decoration (embroidery, printing) into one line, the price includes it.
  • Item names were typed by hand, so the same product may be written several ways. Try a shorter search, or a different word, if you do not see what you expect.
  • Voided and refunded orders are shown with a tag so you can tell them apart.
  • LC in an item means left chest (embroidery position), not Lewis Cass.

Adding your own abbreviations

Open this file with Notepad (right-click → Open with → Notepad), find the section marked ABBREVIATIONS, copy an existing line, and change the words. Save the file and reopen it. Words in a group are treated as the same thing.

Load the old-store data

This is a one-time step. Choose the OrderHistory-OldStore.json file. The app keeps its own copy, so you can remove the original afterward.

Shopify connection

Connects the app to your current store so new orders show up here as New #. The app only reads orders. The Client secret is stored encrypted on this computer only.

Shared database connection

Connects this computer to the shop's shared notes and order board (a free Cloudflare database). The token is stored encrypted on this computer only.
